#  Hair Day

Sistema web de agendamento para barbearia, desenvolvido para permitir que clientes realizem agendamentos de forma prática e organizada.

---

##  Sobre o projeto

O Hair Day é uma aplicação web onde os usuários podem:

- visualizar horários disponíveis
- realizar agendamentos
- cancelar agendamentos
- visualizar horários cadastrados

---

#  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Webpack
- JSON Server
- Git e GitHub

---

#  Como executar o projeto

## Clonar repositório

```bash
git clone https://github.com/MariahNavarro/Hair-Day.git

```

## Instalar dependências

```bash
npm install

```
## Rodar projeto

```bash
npm run dev

```
